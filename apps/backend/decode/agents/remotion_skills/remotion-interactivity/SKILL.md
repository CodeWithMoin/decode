---
name: remotion-interactivity
description: Structure generated scene elements so creators can direct them safely.
---

Keep creator-editable values in component props and use each declared control in the scene.
Controls should affect meaningful labels, colors, emphasis, or pacing, not implementation
details. Keep fixed copy next to the element it labels. Preserve a stable, simple element
structure so later human directions can target one scene without rewriting the production.
