Design for the supplied fixed canvas, not for a responsive webpage. Establish one focal
idea, use generous safe margins, and make text readable at video scale. Prefer a single
coherent composition over panels, cards, or dashboard chrome. Use the existing Decode
runtime only; do not scaffold a project or start a preview server.
