Choose the smallest relevant craft skill before authoring. Use markup for all scenes;
add interactivity for editable structure, captions for timed language, maps for geography,
and multimedia only when media is present. Animation must be a deterministic function of
the current frame. Do not scaffold projects, install packages, run commands, or edit files.
